# Plans

This directory stores all agentic plans created while working on this project.
Whenever an agent produces a plan for a task, it must be saved here as a Markdown file before implementation begins.

## Naming convention

Use `YYYY-MM-DD-<short-slug>.md`, for example `2026-10-14-rag-pipeline-redesign.md`.
If multiple plans are created on the same day for the same topic, append a suffix such as `-v2`.

## Plan contents

Each plan file should include:

- The task or goal the plan addresses.
- Relevant context and findings from codebase exploration.
- A step-by-step implementation approach.
- Open questions or decisions that need user input.
- Status (draft, approved, in-progress, completed), updated as work progresses.
